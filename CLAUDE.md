# Project: Din LCA Hjælper — Marketing Website

## What This Is
A frontend-only marketing/landing page. No backend, no API, no complex state management.

## Workflow

### 1. Plan Before Building
- For new pages or major sections: sketch the layout plan before writing code
- Agree on structure (sections, responsive breakpoints) before implementation
- If the design direction changes, stop and re-align — don't keep pushing

### 2. Keep It Simple
- Minimal dependencies — don't pull in heavy libraries for simple effects
- Clean, semantic HTML. Accessibility matters.
- Mobile-first responsive design
- If a CSS solution exists, prefer it over JavaScript

### 3. Verify Visually
- Never call a section done without checking responsive behavior
- Test across common breakpoints: mobile (375px), tablet (768px), desktop (1280px+)
- Check that text is readable, spacing is consistent, interactions feel right

## Core Principles

- **Design fidelity**: Match the intended look and feel precisely
- **Performance**: Fast load times. Optimize images, minimal JS, no bloat.
- **Minimal changes**: Touch only what's needed. Don't refactor unrelated sections.
- **No over-engineering**: This is a marketing page, not a SaaS platform. Keep it grounded.
